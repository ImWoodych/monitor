# System Resource Monitor (Real-Time)

Мониторинг нагрузки на ЦП и ОЗУ в реальном времени для Windows.

## Возможности

- Отображение нагрузки на ЦП в процентах с визуальным прогресс-баром
- Отображение использования оперативной памяти (процент, использовано/всего в ГБ)
- Информация о системе: хост, ОС, количество и модель процессоров
- Настраиваемый интервал обновления
- Обновление на месте без очистки экрана и дублирования строк

## Установка

### Для запуска из исходников

```bash
# Запуск с интервалом по умолчанию (1 секунда)
node monitor.js

# Запуск с интервалом 5 секунд
node monitor.js --interval 5
```

### Компиляция в .exe

```bash
# Установка pkg
npm install -g pkg

# Компиляция
pkg monitor.js --targets node18-win-x64 --output monitor.exe
```

## Использование

```bash
# Интервал по умолчанию (1 секунда)
monitor.exe

# Указание интервала через --interval
monitor.exe --interval 5

# Короткий параметр -i
monitor.exe -i 3
```

## Параметры

| Параметр      | Описание                  | По умолчанию |
|---------------|---------------------------|--------------|
| `--interval`  | Интервал обновления (сек) | 1            |
| `-i`          | Короткая форма            | 1            |

## Технические детали

- **Язык:** Node.js (JavaScript)
- **Платформа:** Windows
- **Сбор данных:** PowerShell CIM (Win32_Processor, Win32_OperatingSystem)
- **Вывод:** ANSI-коды терминала для позиционирования курсора
- **Компиляция:** pkg (обёртка Node.js в standalone .exe)
